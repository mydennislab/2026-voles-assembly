# Gene annotation

EGAPx v0.7 gene annotation for the two vole assemblies, lifted onto the
orientation-corrected, chromosome-named hap1 coordinate systems used in the
manuscript. These are the annotation files the comparative analyses (orthologs,
Ka/Ks, candidate gene loss) were built on.

| File                       | Assembly                                         |
| -------------------------- | ------------------------------------------------ |
| `prairie_hap1_egapx.gff.gz`| Prairie vole (Microtus ochrogaster) hap1         |
| `meadow_hap1_egapx.gff.gz` | Meadow vole (Microtus pennsylvanicus) hap1       |

GFF3, gzip-compressed. The raw reads submitted as transcript evidence and the
assemblies are in ENA study PRJEB108798 (see `../accessions.tsv`); NCBI may also
produce a RefSeq annotation on the public assemblies independently of these.
